# Hosting TBox on Render (HTTPS link from anywhere)

Result: `https://tbox-xxxx.onrender.com` (Render provides the HTTPS certificate). You can add your own domain later in Render > Settings > Custom Domains.

## One-time steps
1. **Put the project on GitHub** (private repo is fine). In the project folder:
   ```
   git remote add origin https://github.com/<you>/tbox.git
   git push -u origin main
   ```
   (`.git` is already initialised with the first commit.)
2. Render dashboard > **New > Blueprint** > connect GitHub > choose the `tbox` repo. Render reads `render.yaml`.
3. Render asks for **TBOX_ADMIN_PASSWORD**: choose a strong one (>= 10 chars, upper + lower case + digit). Click **Apply**.
4. Wait for the deploy (about 2 minutes). Open the `onrender.com` link, sign in as `admin` with that password.
5. In TBox: add your company/site, create a **Gateway** (copy the token), add devices.

## Connect a plant to the cloud
On the PC at the site: `gateway/gateway.json`
```
{ "server_url": "https://tbox-xxxx.onrender.com", "token": "tbx_...", "allow_writes": false }
```
then `start_gateway.bat`. The gateway connects outward over HTTPS; nothing at the plant is exposed.

## Important facts about Render
* **Plan:** the blueprint uses `starter` because TBox stores data in SQLite on a **persistent disk** (1 GB mounted at `/var/data`). Render's free plan has no disk: data would be erased on every restart/deploy, so do not use it for real data.
* Keep the service on one instance (SQLite is single-writer).
* **Backups:** TBox makes a verified backup daily on the same disk. Also download them regularly (Settings > Database backups > Download) so a disk problem cannot take your history with it.
* `TBOX_SECRET` is generated by Render and kept in its environment; do not change it (stored credentials are encrypted with it).
* Updates: push to GitHub; Render redeploys automatically (`autoDeploy: true`). Database migrations run on start.
* Logs: Render dashboard > Logs.
